### Опыт - 1+ год

Специализируюсь на создании Telegram-ботов любой сложности.

**Что умею:**
- Боты для магазинов - каталоги, корзина, онлайн-оплата, выгрузка заказов
- Админ-панели прямо в Telegram - рассылки, статистика, управление пользователями
- Интеграция с любыми API - платёжные системы, CRM, внешние сервисы
- Работа с базами данных - проектирование схем, оптимизация запросов
- Многопользовательские боты с гибкой логикой и состояниями

**Самооценка:** Middle+++ — проектирую архитектуру с нуля, пишу чистый поддерживаемый код, разбираюсь в бизнес-логике заказчика и предлагаю оптимальные решения.
